# Preserved source candidates

`original_sources/` contains byte-identical snapshots of every original research
Python file, including both identical solver copies. These are provenance only,
excluded from package discovery and canonical execution.

`deprecated_candidates/` retains earlier Experiment 3 code/results and ambiguous
or duplicate artifacts. No originals have been deleted. Earlier route-diversity
experiments are different experimental designs; they are not merged into 3A/3B.
Actual thesis authorship of alternate figure variants cannot be proved from
filenames. Consult the audit and migration manifest before any future deletion.
